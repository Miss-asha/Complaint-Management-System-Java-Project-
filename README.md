## ? Features
- ?? **Role-Based Authentication:** Distinct views for Students and Administrators with password hashing.
- ?? **Institutional Email Validation:** Requires college email domain (`@nhitm.ac.in`).
- ?? **Ticket Workflow:** Real-time status transitions (`Pending` ? `In Progress` ? `Resolved` ? `Rejected`).
- ?? **Image Attachments:** Secure file uploads supporting complaint proof.
- ?? **Admin Dashboard:** Central moderation, filtering, and status controls.
